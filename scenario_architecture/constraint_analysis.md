# Component A: System Architecture and Deployment Justification

# Task A1 — Constraint Analysis

**Latency.** A refrigeration failure raises cargo temperature by ~1°C/minute, so LogiEdge must detect a fault signature and alert within a strict 90-second SLA. Cloud inference cannot guarantee this: even though rural cellular round-trip latency is often only a few hundred milliseconds, India's rural network congestion, packet retransmissions, and coverage loss make a *guaranteed* bound infeasible, and complete outages take cloud inference offline entirely. Edge inference processes a 30-second feature window locally in well under one second (<50 ms typical on Pi-class hardware), so only an on-truck architecture can consistently meet the SLA.

**Bandwidth.** Each truck streams temperature (1 Hz, 4 bytes/sample) at 345.6 KB/day and 3-axis vibration (500 Hz, 12 bytes/sample) at 518.4 MB/day — roughly 518.75 MB/truck/day raw. At ₹0.10/MB, that is ₹51.88/truck/day, or **₹132,294/month for the 85-truck pilot fleet** (₹412,446/month at 265-truck full scale). LogiEdge instead transmits only periodic health summaries and anomaly alerts (~200 bytes/minute ≈ 0.288 MB/truck/day), cutting pilot-fleet communication cost to **₹73.44/month** — a reduction of more than 99.9% in both bandwidth and cost, which is what makes fleet-scale deployment economically viable.

**Connectivity.** The Nashik–Aurangabad route has seven documented cellular dead zones, each lasting 35–90 minutes. A cloud-only system goes fully blind during these gaps — exactly the failure mode behind the ₹28 lakh vaccine-spoilage incident, where a compressor failure occurring mid-gap would go completely undetected. LogiEdge's edge node keeps sensing, preprocessing, and classifying locally regardless of connectivity state: a Critical detection triggers an immediate local driver alarm, is written to a persistent local alert log (append-only JSONL on disk), and is synchronised to the operations centre over MQTT (QoS 1) as soon as coverage returns — monitoring never depends on the network being up.

**Privacy.** FreightBridge's pharmaceutical clients require proof that cargo-condition data cannot be accessed by unauthorised third parties. A cloud-centric design would continuously upload raw high-frequency telemetry — temperature, vibration, routing, and cargo-handling patterns — over public cellular links, widening the exposure surface unnecessarily. LogiEdge performs all inference on-device and uploads only the classified cargo state (Normal/Warning/Critical), timestamped alerts, and audit-log entries required for compliance, all protected with TLS. Raw sensor data never leaves the truck, which directly supports the contractual chain-of-custody and confidentiality guarantees FreightBridge's clients require.

**Conclusion.** Latency, bandwidth, connectivity, and privacy all point in the same direction: cloud-only inference cannot meet the 90-second SLA, costs over ₹132,000/month more than necessary for the pilot fleet, fails during the very connectivity gaps that caused FreightBridge's prior incidents, and exposes far more raw data than a pharmaceutical client's compliance requirements allow. Edge AI is the only architecture that satisfies all four constraints simultaneously, making it the correct choice for the FreightBridge cold-chain pilot.
